Photos and data for the Coorparoo Haven TV welcome app. Resized photos, no metadata.

## Transport data

transport/departures.json lists the next 8 days of bus and train departures for the stops near the house. A GitHub Action (.github/workflows/bake-departures.yml) rebuilds it every day at 3:17am Brisbane time using transport/bake_departures.py.

Timetable data: Translink, Department of Transport and Main Roads (Queensland), SEQ GTFS, licensed under Creative Commons Attribution 4.0 (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/ . Source: https://www.translink.com.au/about-translink/open-data . The data has been filtered to four stops and reformatted.
